\doxysubsection{Description détaillée}
Orchestre l\textquotesingle{}analyse de traçabilité sur les trois niveaux d\textquotesingle{}exigences. 

Reçoit les vecteurs d\textquotesingle{}exigences du module 1 via {\ttfamily \doxylink{class_moteur_tracabilite_abc77ccb38fd1de0d00636f875b271528}{set\+Donnees()}}, exécute l\textquotesingle{}analyse en deux passes (SSS→\+SRS puis SRS→\+SDD), calcule les taux de couverture et expose les résultats sous forme d\textquotesingle{}un {\ttfamily \doxylink{struct_rapport_tracabilite}{Rapport\+Tracabilite}} destiné au module 3.

Peut être piloté de manière asynchrone via {\ttfamily \doxylink{class_thread_manager}{Thread\+Manager}}.
