Description détaillée

Orchestre l'analyse de traçabilité sur les trois niveaux d'exigences.

Reçoit les vecteurs d'exigences du module 1 via setDonnees(), exécute l'analyse en deux passes (SSS→SRS puis SRS→SDD), calcule les taux de couverture et expose les résultats sous forme d'un RapportTracabilite destiné au module 3.

Peut être piloté de manière asynchrone via ThreadManager.

◆ calculerTaux() [2/4]

void MoteurTracabilite::calculerTaux ( )

Calcule les taux de couverture après l'analyse.

  • tauxSSS_SRS = nb SSS couvertes / nb SSS total
  • tauxSRS_SDD = nb SRS couvertes / nb SRS total
  • tauxGlobal = tauxSSS_SRS × tauxSRS_SDD

Des avertissements sont ajoutés aux liens brisés si un vecteur est vide.
