Description détaillée

Exigence de niveau SRS (Software Requirements Specification).

Hérite de Exigence. Contient :

  • tracabilite : identifiants des exigences SSS qu'elle couvre,
  • cibles : composants ou modules ciblés par l'exigence,
  • necessaireA : projets concernés par cette exigence.
