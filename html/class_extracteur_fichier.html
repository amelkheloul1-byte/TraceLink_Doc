std::vector< std::string > ExtracteurFichier::chargerSharedStrings ( zip_t * archive) const
private

Charge le dictionnaire des textes partagés d'Excel.

  • Dans un .xlsx, les textes ne sont pas stockés directement dans les cellules pour gagner de la place. Ils sont regroupés dans 'xl/sharedStrings.xml'.
  • Cette méthode :
  1. Ouvre le fichier de dictionnaire dans l'archive ZIP.
  2. Lit tout le contenu XML.
  3. Stocke chaque texte trouvé dans un vecteur où l'indice correspond à l'ID Excel.
  • Paramètres
    archivePointeur vers l'archive ZIP ouverte (libzip).
    Renvoie
    Un vecteur de chaînes de caractères servant de table de correspondance.

Filtre les lignes CSV/XLS colonne par colonne.

Cherche toutes les occurrences du motif regex dans chaque ligne.

Pour chaque ligne :

  • Colonne 1 : identifiant (doit matcher la regex)
  • Colonne 2 : lien de traçabilité si c'est un identifiant, sinon contenu
  • Colonnes suivantes : contenu textuel

Cette méthode est partageable avec le DOCX pour un filtrage uniforme.

Paramètres
lignesRésultat de lireCSV().
format"csv" ou "xls".
Renvoie
Liste des exigences extraites avec métadonnées.

Pour chaque ligne :

  • Colonne 1 : identifiant principal (doit matcher la regex)
  • Colonne 2 : lien de traçabilité si c'est un identifiant valide (commence par EXIGENCE_ ou SDD_)
  • Colonnes suivantes : contenu textuel ignoré
Paramètres
lignesRésultat de lireCSV().
format"csv" ou "xls".
Renvoie
Liste des exigences extraites avec métadonnées.

Algorithme :

  • Pour chaque ligne du vecteur d'entrée, lance std::sregex_search pour trouver le premier identifiant.
  • Vérifie si l'identifiant trouvé existe déjà dans une liste de mémorisation afin de bloquer les doublons.
  • Chaque match génère un objet ExigenceExtraite renseigné avec : identifiant = chaîne matchée contenuBrut = ligne complète fichierSource, formatSource, numeroLigne
Paramètres
lignesRésultat de lireCSV() ou lireDocx().
format"csv", "xls" ou "docx".
Renvoie
Liste de toutes les exigences détectées.

std::vector< std::pair< int, std::string > > ExtracteurFichier::lireCSV ( const std::string & extension) const
private

Lit un fichier CSV/XLS ligne par ligne.

Lit un fichier texte tabulaire (.csv ou .xls).

Lit un fichier texte tabulaire (.csv ou .xls) ligne par ligne.

Retourne un vecteur de (numéroLigne, ligne brute) sans filtrage. Le délimiteur (virgule ou point-virgule) est auto-détecté. Les colonnes sont séparées mais la ligne est retournée brute pour que filtrerLignes() puisse la traiter colonne par colonne.

Paramètres
extension"csv" ou "xls"
Renvoie
Vecteur de (numéroLigne, contenu brut de la ligne).

Retourne chaque ligne brute (sans concaténation des colonnes) pour que filtrerLignes() puisse traiter les colonnes séparément. Le délimiteur (virgule ou point-virgule) est auto-détecté. Les lignes entièrement vides sont ignorées.

Paramètres
extension"csv" ou "xls"
Renvoie
Vecteur de (numéroLigne, ligne brute).

Algorithme :

  • Ouvre le fichier en mode texte.
  • Lit ligne par ligne avec std::getline.
  • Pour chaque ligne, teste les délimiteurs ';' et ',' et choisit celui qui génère le plus de colonnes (auto-détection).
  • Concatène toutes les cellules en une chaîne unique par ligne.
  • Ignore les lignes entièrement vides.
Renvoie
Vecteur de (numéroLigne, texte concaténé).

Extrait le texte brut d'un fichier .docx.

Renvoie

Algorithme :

  • Ouvre l'archive ZIP avec libzip
  • Localise word/document.xml dans l'archive
  • Lit le contenu XML et on le met en mémoire
  • Parse le XML avec pugixml
  • Extrait le texte de chaque paragraphe
