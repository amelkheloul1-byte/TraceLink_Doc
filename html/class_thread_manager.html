Description détaillée

Gère l'exécution asynchrone de l'analyse de traçabilité.

Encapsule un std::thread qui exécute séquentiellement MoteurTracabilite::analyserTracabilite() puis MoteurTracabilite::calculerTaux(). Un std::atomic<bool> permet de consulter l'état d'avancement sans bloquer le thread principal.

Le destructeur garantit que le thread est joint avant la destruction de l'objet, évitant ainsi l'appel à std::terminate().
