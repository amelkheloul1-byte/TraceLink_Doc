\doxysubsection{Description détaillée}
Gère l\textquotesingle{}exécution asynchrone de l\textquotesingle{}analyse de traçabilité. 

Encapsule un {\ttfamily std::\+thread} qui exécute séquentiellement {\ttfamily \doxylink{class_moteur_tracabilite_ad2fad491850ace8d8092eabc4e6b61b5}{Moteur\+Tracabilite::\+analyser\+Tracabilite()}} puis {\ttfamily \doxylink{class_moteur_tracabilite_aebf35cbed81371cefd10246ae6aa89cd}{Moteur\+Tracabilite::\+calculer\+Taux()}}. Un {\ttfamily std::\+atomic$<$bool$>$} permet de consulter l\textquotesingle{}état d\textquotesingle{}avancement sans bloquer le thread principal.

Le destructeur garantit que le thread est joint avant la destruction de l\textquotesingle{}objet, évitant ainsi l\textquotesingle{}appel à {\ttfamily std::\+terminate()}.
